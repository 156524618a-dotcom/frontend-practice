# 前端练习册

从简单页面开始学习 React。每个项目都包含源代码和运行说明。

仓库地址：[156524618a-dotcom/frontend-practice](https://github.com/156524618a-dotcom/frontend-practice)

| 项目 | 内容 | 学习重点 |
| --- | --- | --- |
| [01 · 个人介绍卡片](./01-profile-card) | 个人信息、兴趣标签、可展开的学习目标 | JSX、组件、props、useState、条件渲染 |
| [02 · 计数器实验室](./02-counter) | 对比基础计数器与加一、减一、重置的修改版 | useState、onClick、disabled、边界限制 |
| [03 · 商品列表与筛选](./03-product-filter) | 基础清单与支持搜索、分类、库存组合筛选的商品卡片 | 受控输入、filter、map、key、条件渲染 |

进入 `01-profile-card` 后，运行 `npm install` 和 `npm run dev` 即可预览。

练习二：进入 `02-counter`，运行 `npm install` 和 `npm run dev`，打开终端中的地址（默认端口 5174）。

练习三：进入 `03-product-filter`，运行 `npm install` 和 `npm run dev`，打开终端中的地址（默认端口 5175）。
