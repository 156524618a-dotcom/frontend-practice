# 本地验证记录

## 环境

- Node.js 26.1.0、React/React DOM 19.3.1、Ant Design 6.7.0。
- TypeScript 5.9.3、Vite 8.3.8、Ant Design Icons 6.3.4。
- Windows 本地 Edge + Python Playwright，无远程运行环境。

## 验证结果

- `npm.cmd run build`：TypeScript 严格类型检查和生产构建通过。
- 开发服务（5180）与生产预览（4180）均运行了 `scripts/test_ui.py` 的交互检查，通过。
- 搜索、分页、单选、键盘选择、按钮禁用条件、所选任务信息核对正确。
- 顶栏/侧栏模块切换、浏览器后退和帮助弹窗正确。
- 项目之间任务隔离、空项目、必填与重复编号校验、本机持久化和损坏数据恢复正确。
- 新建任务支持必填和重复编号校验、键盘单选模型、框图缩放和拖动。创建后自动选中，刷新后在所属项目中恢复。
- 等分配演示核对了结果值、参数修改后撤下旧结果、任务时间换算、无参与组件、无效目标和目标不可达时的反馈。
- 1366×768、1440×900、1920×1080、1100×800 均无页面横向溢出，开始按钮保持在视口内。
- 两个新增界面在 1100×800 检查了主要操作或结果是否位于视口内，并在 1440×900 保存截图。
- 浏览器控制台无警告、无错误；运行时无远程 HTTP 请求。
- 实际截图保存在 `docs/screenshots`。

默认生产包包含 antd 相关依赖，JS 约 1028 kB（gzip 约 328 kB），构建工具提示单包超过建议阈值。
